How to
- New synced table: migration in supabase/migrations (dry run, then
  npx supabase db push), add it to powersync/sync-config.yaml, then
  PowerSync dashboard > Sync Streams > paste the file > Validate > Deploy,
  and add it to app/lib/data/local_schema.dart. Without the PowerSync
  step, new rows upload and then vanish from phones.
- Tests: cd app; flutter analyze; flutter test (the full suite runs on
  GitHub for pull requests into main). Server: cd supabase/tests; npm ci;
  npm test.
